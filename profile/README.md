<h3 align="center">Deki Engine</h3>

<p align="center">
  A modular C++ engine with a visual editor. Tiny enough for an MCU.
</p>

<p align="center">
  <a href="https://dekiengine.com">Website</a> ·

</p>

Drive an LCD from an ESP32, run the same project on Windows through SDL3, or
drop the renderer entirely and ship a headless service. Every part is a
package: take what you need.

**Start here**

- [deki-engine](https://github.com/dekiengine/deki-engine): the runtime
- [deki-editor](https://github.com/dekiengine/deki-editor): the visual editor
- [deki-demo](https://github.com/dekiengine/deki-demo): one project, every board
- [registry](https://github.com/dekiengine/registry): the package registry

Every other `deki-*` repository here is a package. Browse them all at
[dekiengine.com/packages](https://dekiengine.com/packages/).

Deki is free and Apache 2.0, built by one person after work.
[Sponsoring](https://github.com/sponsors/dekiengine) buys more hours and more
boards to test on.
